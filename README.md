🤖 QA Oracle: Production-Grade Agentic RAGMoving beyond "vibes-based" AI development. This repository contains a modular, high-performance Retrieval-Augmented Generation (RAG) framework designed for technical research and enterprise-grade reliability.  🏗️ The Architecture: "The Brain, The Memory, & The Translator"This system treats RAG as a design space of swappable "slots" rather than a rigid script.  The Brain (Inference): Powered by Groq (Llama 3.1/3.3) for hyper-fast multi-node reasoning.  The Memory (Vector Store): ChromaDB for local, persistent document storage.  The Translator (Embeddings): Local Ollama (nomic-embed-text) for privacy-conscious vectorization.  The Orchestrator: LangGraph transforms linear pipelines into resilient, cyclical state machines.  🌟 Key Features1. Meticulous Ingestion (Incremental Sync)Stop re-embedding your entire library. Our ingestion pipeline performs a "Metadata Handshake" to identify the Delta—only processing brand-new or changed files.  Metadata Handshake: Uses source paths to diff local folders against the DB.  Recursive Chunking: 1000-character chunks with a 200-character "context bridge" overlap.  2. Agentic WorkflowUnlike standard RAG, the "Oracle" uses a multi-node assembly line to verify information at every step:  Gatekeeper: Guards against prompt injections and out-of-scope queries.  Architect: Plans the search scope (Global vs. Scoped).  Researcher: Executes high-precision searches using MMR and Metadata Filters.  Auditor: A real-time safety layer that compares the final answer against source summaries to kill hallucinations.  3. Evaluation: The LabWe measure success using the RAG Triad to decouple Retriever performance from Generator accuracy:  Faithfulness: Did the LLM make it up?   Answer Relevance: Did it actually answer the user?   Context Precision: Was the retrieved data high-signal?   MRR (Mean Reciprocal Rank): Programmatic benchmarking of the "Librarian's" accuracy.
